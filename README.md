# 승규의 학습 영상

아빠(마잭)가 승인한 유튜브 영상만 볼 수 있는, 승규(초3)·시온(초2)을 위한 잠금형 학습 영상 플레이어.
유튜브 앱 없이도 필요한 영상만 안전하게 볼 수 있도록 만든 정적 웹앱입니다.

## 빠른 시작 (로컬 확인)

```bash
npm test          # 로직 테스트 실행
npm run serve      # http://localhost:5173 에서 로컬 서버 실행
```

## 새 주제·영상 추가하기 (가장 자주 할 일)

주제는 앞으로 계속 바뀝니다. **코드는 건드리지 않고** 아래 명령 한 줄로 추가합니다.

```bash
# 새 주제를 만들면서 첫 영상 추가
node tools/add-video.mjs --new-topic "우주 탐사" --id space --emoji 🚀 \
  --section "1단계 · 한국어" --lang ko "<유튜브 URL>"

# 이미 있는 주제에 영상 추가
node tools/add-video.mjs --topic civil-revolutions \
  --section "2단계 · 영어로 다시 보기" --lang en "<유튜브 URL>"
```

- URL을 실제 유튜브에 검증(존재 여부, 임베드 가능 여부, 길이)한 뒤에만 `data/topics.json`에 추가합니다. 검증에 실패하면(비공개, 삭제됨, 임베드 차단 등) 이유를 출력하고 추가하지 않습니다.
- 추가되는 영상은 항상 `approved: false` 상태입니다. **부모 모드에서 직접 승인해야 승규 화면에 나타납니다.**
- `--id`는 새 주제를 만들 때만 필요합니다(한글 제목은 자동 slug가 안 되므로 영문 id를 직접 지정하세요). 생략하면 임의 id가 생성됩니다.
- `--section`은 자유 텍스트입니다. 주제마다 원하는 대로("1단계/2단계", "기초/심화" 등) 쓰면 됩니다.

## 영상 승인하기 (부모 모드)

1. 태블릿(또는 아무 브라우저)에서 앱을 엽니다.
2. 헤더의 🎬 로고를 **5번 빠르게 탭**합니다.
3. 처음이면 4자리 PIN을 새로 설정하고, 그 다음부터는 입력합니다.
4. "승인 대기 중인 영상" 목록에서 **미리보기**(실제 유튜브에서 열림)로 내용을 확인한 뒤 **승인**을 누릅니다.
5. 승인은 **그 기기(브라우저)에만** 저장됩니다. 승규 태블릿에서 보이게 하려면 반드시 승규 태블릿에서 승인하세요.

같은 화면에서 하루 시청 시간 한도 변경, 오늘 기록 초기화, 재생 오류 기록 확인도 할 수 있습니다.

## 영상이 죽었는지 주기적으로 확인하기

유튜브 영상은 시간이 지나면 삭제되거나 비공개로 바뀔 수 있습니다. 한 달에 한 번 정도:

```bash
node tools/verify-videos.mjs          # 확인만 (dry run)
node tools/verify-videos.mjs --fix    # 실패한 영상을 approved:false로 내리고 저장
```

## 안전장치 설계 (참고)

- **완전 잠금 플레이어**: 유튜브 iframe 위에 투명 오버레이를 덮어 로고·제목·채널·추천영상 클릭을 물리적으로 차단합니다. 재생/탐색은 직접 만든 컨트롤바로만 가능합니다.
- **자동 연속재생 없음**: 영상이 끝나면 목록으로 돌아갑니다.
- **부모 승인 필수**: `add-video.mjs`로 추가된 영상은 기본 비공개이며, 부모가 실제로 보고 승인해야 노출됩니다.
- **하루 시청 시간 한도**: 재생 중에만 초 단위로 누적되며, 한도에 닿으면 즉시 일시정지되고 잠김 화면으로 전환됩니다.
- **PIN은 억제책**: 초3 기준의 장치일 뿐 보안 경계가 아닙니다. 기기 자체의 패밀리 링크 등과 병행하세요.

## 파일 구조

```
data/topics.json       주제·영상 데이터 (유일한 편집 지점)
src/                    앱 로직 (뷰, 플레이어, 시청기록, 승인, 부모모드)
tools/                  add-video.mjs, verify-videos.mjs, 로컬 서버
tests/                  node --test 대상 (순수 로직만)
```

## 태블릿에 설치하기 (홈 화면 추가)

배포된 URL을 안드로이드 크롬으로 연 뒤, 메뉴 → **홈 화면에 추가**를 누르면 주소창 없는 전체화면 앱으로 실행됩니다. 이 상태에서는 다른 사이트로 이동할 방법이 없습니다.
